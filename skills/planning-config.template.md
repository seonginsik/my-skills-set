# <프로젝트 이름> 기획 설정 (planning-config)

> 공통 기획 스킬(`skills/<이름>/SKILL.md`)이 이 프로젝트에서 쓰는 값입니다. 스킬에는 고유 이름 · 주소를 적지 않고, 이 파일에서 찾습니다.
> 절 이름 = 스킬 이름. 값이 바뀌면 이 파일만 고칩니다. 아직 정하지 않은 칸은 '미정'으로 두고, 쓰지 않는 절은 지워도 됩니다.
> 이 파일을 프로젝트 폴더에 `planning-config.md`로 복사해 채웁니다.

---

## 기능정의서 (`spec-sheet-writing`)

| 항목 | 값 |
|---|---|
| 도구 | 엑셀 파일 / 구글 시트 / 노션 데이터베이스 |
| 원본 위치 | <파일 경로 · 시트 주소 · 노션 페이지 주소> |
| 보안 | <대외비 여부 · PC 사본 허용 여부> |
| 탭 번호 | <탭 이름 = 시트 gid 또는 데이터베이스 ID> |
| 주체 | <예: 판매자 · 운영자 · 소비자> |
| 기능 ID 접두어 | <주체별 접두어-영역-번호> |
| 회사 원본 양식 | <있으면 경로, 없으면 없음> |
| 도구 명령 | <읽기 · 미리 보기 · 쓰기 · 미정 대조 명령, 없으면 수동> |
| 화면설계 대응표 | <화면 ID ↔ 노드 표 경로> |
| 정책 미정 표 위치 | <정책 문서의 미정 질문 절> |
| 용어 · 말투 | <용어집 위치, 주체별 말투> |
