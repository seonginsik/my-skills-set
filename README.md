# my-skills-set

AI(Claude Code)가 기획 문서를 사람이 바뀌어도 같은 규칙으로 쓰게 하는 기획 스킬 모음입니다.
도메인 · 프로젝트와 관계없이 쓰고, 프로젝트마다 다른 값은 각 프로젝트의 `planning-config.md`에 둡니다.

- 스킬 목록 · 설치 · 고치는 규칙: [skills/README.md](skills/README.md)
- 스킬 원본: `skills/<이름>.md` · Claude Code 등록 파일: `.claude/skills/<이름>/SKILL.md`
- 새 프로젝트 설정 빈 틀: [skills/planning-config.template.md](skills/planning-config.template.md)
